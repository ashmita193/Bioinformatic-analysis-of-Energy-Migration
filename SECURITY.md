# Security Policy

## Supported Versions

This repository is intended for research and educational purposes. Security updates are provided only for the latest version available on the `main` branch.

| Version | Supported |
|---------|-----------|
| Latest (`main`) | ✅ |
| Previous releases | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it by opening a **private GitHub security advisory** or by contacting the repository maintainer directly.

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce the vulnerability
- The affected script(s), if known
- Any potential impact
- Suggested mitigation, if available

### Response Timeline

- **Acknowledgement:** within 5 business days
- **Initial assessment:** within 14 business days
- **Resolution:** A fix will be developed and released as soon as reasonably possible if the vulnerability is confirmed.

### Scope

This repository contains Python scripts for bioinformatics data analysis and visualization. Security issues may include, but are not limited to:

- Arbitrary code execution
- Dependency-related vulnerabilities
- Unsafe file handling
- Credential or secret exposure
- Malicious input that could compromise data integrity

Issues related to scientific methodology, statistical analysis, or biological interpretation are **not** considered security vulnerabilities and should instead be reported through the GitHub Issues page.

Thank you for helping improve the security and reliability of this project.
